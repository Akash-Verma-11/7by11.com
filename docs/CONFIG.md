# Configuration reference

Compose reads .env and injects the application settings listed in compose.yaml. A direct Python process reads only its operating-system environment. Set variables in that terminal before python run.py; it does not load .env itself. Never commit credential files.

| Variable | Default or source | Meaning |
|---|---|---|
| POSTGRES_PASSWORD | Generated by scripts/init-env.py | Compose database credential; the generated hexadecimal form is safe inside the database URL. Editing it does not rotate a password in an existing volume. |
| DATABASE_URL | Constructed by Compose | PostgreSQL connection URL. If absent, the app uses SQLite. Never set a live URL when running tests. |
| SQLITE_PATH | data/7by11.db | Local SQLite file; used only without DATABASE_URL. |
| SEED_DEMO | true | Insert missing sample accounts, stores and products at startup. false prevents new inserts but does not remove existing demo data. |
| DEMO_PASSWORD | 7by11Demo!2026 | Password for newly inserted demo accounts only. Changing it does not update existing password hashes. |
| PAYMENT_MODE | demo | The only enabled mode. Other values deliberately reject checkout; they do not activate a real gateway. |
| PUBLIC_ORIGIN | http://localhost:3000 | Comma-separated allowed browser origins for writes, with scheme and port, without spaces or trailing slash. |
| ALLOWED_HOSTS | localhost,127.0.0.1 | Comma-separated trusted hostnames, without schemes or spaces. Future domain entries are commented in .env.example. |
| BIND_ADDRESS | 127.0.0.1 | Python development-server bind address. Docker uses Gunicorn's explicit bind instead. |
| PORT | 3000 | Python development-server port. Docker's Gunicorn port is set in Dockerfile and Compose mapping. |
| BASE_URL | http://localhost:3000 | Destination for scripts/smoke.py only. For future HTTPS use your HTTPS URL. |

Database usernames and database name are sevenbyeleven in Compose. PostgreSQL stores persistent data in the named postgres-data volume. Caddy uses caddy-data and caddy-config volumes. Changes to PUBLIC_ORIGIN, ALLOWED_HOSTS or other injected settings require docker compose up -d to recreate the app. Keep PAYMENT_MODE=demo even after enabling HTTPS until a real provider integration is implemented.

Version-one policy constants live in source: sessions expire after 3600 seconds; login throttles after 10 failed attempts for the same email; delivery codes expire after 600 seconds with 5 wrong attempts; cart quantity limit is 20 per product; catalog page size is 24; media upload limit is 1.5 MB with a 2 MB request ceiling; seller commission is an illustrative 10 percent. These are not all environment switches. Change them in code with corresponding tests when your business policy changes.
